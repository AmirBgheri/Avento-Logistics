# Avento Logistics — Premium Animated Website

نسخه بازطراحی‌شده وب‌سایت فارسی Avento Logistics. سایت **React نیست**؛ تمام صفحات HTML مستقل دارند و CSS و JavaScript در فایل‌های خوانا و جدا نگهداری شده‌اند.

## ساختار

```text
avento-logistics/
├── index.html             صفحه اصلی، خدمات و مسیرها (#services, #routes)
├── quote.html             فرم کامل استعلام حمل
├── about.html             درباره ما
├── contact.html           تماس با ما
├── assets/
│   ├── images/
│   │   ├── air-freight.webp
│   │   ├── sea-freight.webp
│   │   └── road-freight.webp
│   ├── css/
│   │   ├── styles.css     ساختار و چیدمان پایه
│   │   └── premium.css    ظاهر جدید، هاورها، انیمیشن‌ها و ریسپانسیو
│   └── js/
│       ├── navigation.js منوی واکنش‌گرا و وضعیت لینک‌ها
│       ├── routes.js     نقشه تعاملی مسیرها
│       ├── motion.js     افکت اسکرول، ظاهر شدن عناصر و نوار پیشرفت
│       └── quote.js      ارسال فرم و انتخاب اولیه روش حمل
└── api/
    ├── quote.php          کد اولیه پردازش سمت سرور فرم
    └── config.example.php
```

## بهبودهای نسخه Premium

- بخش Hero با پس‌زمینه چندلایه، تیتر شاخص و همان سه تصویر بهینه‌شده Air/Sea/Road.
- تصاویر با هاور زوم بسیار کم و چرخش ظریف، بدون تغییر چیدمان صفحه.
- نوار ناوبری نیمه‌شفاف هنگام اسکرول، نشانگر ظریف میزان اسکرول و هاورهای خطی منو.
- دکمه‌های متحرک و کارت‌های خدمات قابل‌کلیک. از حمل هوایی، دریایی و زمینی روش حمل به صورت خودکار در فرم استعلام انتخاب می‌شود.
- انیمیشن ورود سکشن‌ها هنگام اسکرول و حرکت ظریف روی کارت‌های مزیت‌ها و فرآیند همکاری.
- نقشه مسیرها با خطوط متحرک در مسیر انتخابی؛ نقشه شماتیک است و ادعای مسیر واقعی/لحظه‌ای ندارد.
- فرم استعلام و صفحات درباره ما/تماس با ما هماهنگ با هویت بصری جدید.
- استفاده از IntersectionObserver و حرکت عمدتاً مبتنی بر transform/opacity، بدون کتابخانه انیمیشن و بدون بارگذاری تصاویر اضافی.
- احترام به تنظیمات `prefers-reduced-motion` و حفظ حالت قابل استفاده بدون JavaScript.

## مشاهده روی کامپیوتر

1. فایل ZIP را Extract کنید.
2. پوشه `avento-logistics` را در VS Code باز کنید.
3. `index.html` را با افزونه Live Server اجرا کنید.
4. برای تست موبایل، ابزار DevTools و حالت Responsive را فعال کنید.

## انتشار روی هاست

فایل‌های داخل پوشه `avento-logistics` را به ریشه سایت (معمولاً `public_html`) منتقل کنید، به‌طوری که فایل `index.html` مستقیماً در ریشه قرار بگیرد. SSL و DNS باید از قبل تنظیم شده باشند.

## نکته مهم درباره ایمیل فرم

**این نسخه صرفاً طراحی و تجربه کاربری را ارتقا می‌دهد؛ اتصال واقعی فرم استعلام به ایمیل هنوز نیاز به پیکربندی سرویس ایمیل روی هاست دارد.**

- صندوق `logistics@avento-logistics.com` باید واقعاً ایجاد و آزمایش شود.
- فایل `api/config.example.php` فقط نمونه است و فایل پیکربندی واقعی و داده‌های محرمانه را نباید در مخزن عمومی قرار داد.
- فایل PHP کنونی از `mail()` استفاده می‌کند؛ پیش از انتشار عمومی توصیه می‌شود ارسال احرازشده SMTP (مانند PHPMailer)، محافظت قوی ضداسپم و آرشیو امن درخواست‌ها اضافه شود.
- تا وقتی پیکربندی سرور ناقص است، فرم باید خطای مناسب نشان دهد، نه پیام موفقیت جعلی.

## آزمایش‌ها

- بازبینی در مرورگر Chromium روی عرض 1440، 900 و 390 پیکسل؛ بدون اسکرول افقی ناخواسته.
- بارگذاری هر سه تصویر و بررسی نبود خطای JavaScript.
- تست بازشدن منوی موبایل و انتخاب تعاملی مسیر امارات روی نقشه.
- بررسی صفحات about، contact و quote و بررسی لینک‌های داخلی فایل‌ها.
- بررسی صحت نحوی JavaScript و PHP.

این آزمایش‌ها **جای گزارش Lighthouse جدید روی هاست واقعی را نمی‌گیرند**؛ برای مقایسه با امتیاز قبلی، تست Performance/Accessibility/SEO را دوباره روی Mobile و Desktop انجام دهید.
